# report

сборка pdf отчёта для научного руководителя из `paper/preprint.md`.

## запуск

```sh
TMPDIR=/home/esnond/echo/tmp_check/pip-tmp \
PYTHONPATH=/home/esnond/echo/tmp_check/pdflib \
python3 paper/report/build_report.py
```

зависимости: python 3.13, weasyprint 65.1, markdown 3.11, matplotlib 3.11.
шрифты pt serif, pt sans и pt mono скачиваются при первом запуске в
`.cache/fonts/` и распространяются по лицензии sil ofl 1.1.

выход: `build/eidolon-report-ru-2026-10-31.pdf`, `build/*.html` и
`build/*.pdf.sha256`.

## состав

- титул, резюме, статус утверждений, провенанс и декларация об ии;
- содержание, список рисунков и таблиц;
- полный текст препринта без изменения чисел и вердиктов;
- раздел 3.9 с формальными определениями, которых не было в препринте;
- восемь рисунков, одиннадцать таблиц, формулы в svg;
- колофон с лицензиями и границами воспроизводимости.

`paper/report/` исключён из `results/manifest.txt`: это производная вёрстка,
а не научный артефакт. манифест покрывает код, данные, результаты и текст
препринта.
